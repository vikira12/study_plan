나만의 학습 달력, 준비 완료

개인 일정 · 대덕소프트웨어마이스터고 학교 일정 · 공휴일 · 급식을 웹과 배경화면에서 함께 확인하세요.

1. 처음 설치하는 분

  1. 받은 ZIP을 우클릭해 모두 압축 풀기를 선택하세요. ZIP 내부에서 직접 실행하지 마세요.
  2. 압축을 푼 StudyPlanner 폴더에서 설치.cmd를 실행하세요. Node.js 별도 설치나 관리자 권한은 필요하지 않습니다.
  3. 설치가 끝나면 바탕화면의 Study Planner 바로가기로 실행하세요. 서버는 Windows 로그인 때 자동으로 시작합니다.

프로그램 위치: %LOCALAPPDATA%\Programs\StudyPlanner. Windows 보안 경고가 나오면 출처를 확인하세요. 조직 보안 정책을 우회하거나 백신을 끄지 마세요.

2. 배경화면에 달력 띄우기

  1. Lively Wallpaper 공식 홈페이지에서 Lively를 설치하고 실행하세요. Lively는 이 ZIP에 포함하지 않습니다.
  2. Lively에서 배경화면 추가 → URL에 아래 주소를 붙여 넣고 적용하세요.
    http://127.0.0.1:3000/wallpaper.html
  3. Lively 설정에서 Windows 시작 시 실행을 켜세요. 로그인 직후 연결 실패 화면이면 Study Planner를 실행한 뒤 배경화면을 다시 불러오세요.
  4. 달력 상단을 마우스로 끌어 이동하고, 테두리·모서리를 끌어 크기를 바꿉니다. 배경화면 마우스 입력이 안 되면 Lively의 상호작용 설정을 확인하세요.

배경화면은 읽기 전용이며 개인 일정은 약 15초마다 반영됩니다. 오른쪽 급식은 한국 시간 기준 오늘 식단입니다.

3. 일정 작성과 이전

웹의 일정 입력에서 제목과 시작·마감 날짜를 지정하세요. 달력에서 드래그로 기간을 바꾸고, 우클릭으로 완료 여부를 바꿀 수 있습니다. 시간 단위 일정은 사용하지 않습니다.

기존 GitHub Pages 일정은 그 주소의 내 일정 → 개인 일정 내보내기로 다운로드한 뒤, 이 PC의 내 일정 → 개인 일정 가져오기로 옮기세요. 이후 수정은 http://127.0.0.1:3000/에서 해야 배경화면에도 반영됩니다.

각자의 일정은 각자의 PC에 저장합니다. 사용자 계정·PC·Pages 사이의 자동 동기화는 지원하지 않습니다.

4. 백업 · 업데이트 · 제거

  • 정기적으로 개인 일정 내보내기를 사용하세요. 개인 파일은 %LOCALAPPDATA%\StudyPlanner\tasks.json이고, 변경 전 최근 10개 백업은 같은 폴더의 backups에 보관됩니다.
  • 업데이트는 새 ZIP의 설치.cmd를 실행합니다. 설치 파일만 교체하고 개인 일정과 달력 배치는 유지합니다.
  • 제거하려면 설치 폴더의 제거.cmd를 실행하세요. 자동 시작과 바로가기만 해제하고 서버를 종료합니다. 프로그램 폴더는 안내에 따라 직접 지우고, Lively 배경화면도 따로 해제하세요. 개인 데이터는 남습니다.
  • 실행 실패 시 %LOCALAPPDATA%\StudyPlanner\startup.log와 server-error.log를 확인하세요. 다른 앱이 3000 포트를 쓰면 그 앱을 자동 종료하지 않습니다.

인터넷 연결은 학교 일정·급식 갱신에 필요합니다. 공개 자료는 원본과 대조하세요. 앱이 닫혀 있는 동안 마감 알림을 보내는 기능은 지원하지 않습니다.
