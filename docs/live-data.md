# 실시간 공휴일·학교 일정

Node.js 22 이상이 설치된 컴퓨터에서 저장소 최상위 터미널을 열고 `node server.js`를 실행한 뒤, `http://127.0.0.1:3000`에 접속합니다. 프레임워크나 패키지 설치, API 키는 필요하지 않습니다. 서버를 종료하면 실시간 자료는 갱신되지 않지만, 개인 일정은 해당 브라우저의 `localStorage`에 그대로 남습니다.

**주의:** VS Code Live Server나 GitHub Pages처럼 HTML만 제공하는 주소에는 `/api/school-events`가 없습니다. 그런 주소로 열면 학교 일정을 가져올 수 없으므로 위 로컬 서버 주소를 사용하세요. `127.0.0.1`은 접속한 기기 자신을 뜻합니다.

서버는 [Nager.Date의 대한민국 공휴일 API](https://date.nager.at/)와 [대덕소프트웨어마이스터고등학교 공개 학사일정](https://dsmhs.djsch.kr/scheduleH/list.do?m=0203&s=dsmhs)을 읽어 달력에 표시합니다. 공휴일은 하루, 학교 일정은 30분 동안 서버 메모리에 보관해 제공처에 반복 요청하지 않습니다. 갱신에 실패하면 서버가 보관한 마지막 자료를 사용합니다. 2026~2027년 공휴일은 앱에 내장된 자료가 우선 적용됩니다. 임시공휴일이나 학교의 최근 변경 사항은 제공처 반영 시점에 따라 다를 수 있으니 중요한 일정은 학교 원본에서 확인하세요. 학교 홈페이지의 공개 화면 구조가 바뀌면 학교 일정 연결을 수정해야 할 수 있습니다.

동생이 **같은 컴퓨터**에서 시험한다면 위 주소를 그대로 열면 됩니다. 같은 와이파이의 **다른 기기**에서 시험하려면 서버를 `HOST=0.0.0.0`으로 실행하고 컴퓨터의 내부 IP 주소와 포트 `3000`으로 접속합니다. Windows PowerShell 예: `$env:HOST='0.0.0.0'; node server.js`. 방화벽 허용이 필요할 수 있습니다. 인터넷에 직접 공개하는 용도로 이 로컬 서버를 사용하지 마세요. 각 브라우저의 개인 일정은 서로 공유되지 않습니다.
