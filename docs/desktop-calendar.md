# Windows 배경화면 달력

개인 일정과 대덕소프트웨어마이스터고등학교 일정을 웹과 같은 달력으로 표시한다. 배경화면에서는 일정을 수정하지 않는다. 개인 일정은 15초마다 확인하고, 학교 일정은 30분마다 갱신한다. 다음 달이 되면 달력도 자동으로 넘어간다.

## 달력 위치와 크기 조절

- 달력 상단의 월 제목 또는 빈 공간을 마우스로 잡아 화면 안에서 이동한다.
- 달력의 네 변이나 모서리를 잡아 드래그하면 가로·세로 크기가 바뀐다. 별도의 큰 손잡이는 표시하지 않는다.
- **배치 잠금**을 누르면 이동과 크기 조절을 막는다. **배치 잠금 해제**로 다시 조절한다.
- **배치 초기화**를 누르면 화면 오른쪽의 기본 위치와 크기로 돌아온다.
- 마우스를 놓으면 위치·크기·잠금 상태를 `%LOCALAPPDATA%\StudyPlanner\wallpaper-layout.json`에 저장한다. 다시 실행할 때 복원하며 해상도가 달라지면 화면 안에 들어오도록 조절한다. 일정 파일은 바꾸지 않는다.

이 기능은 Lively 배경화면 안에서 달력 패널을 배치하는 방식이다. Windows의 독립 창으로 뜨는 형태는 아니다. [Lively 공식 입력 안내](https://github.com/lively-community/lively/wiki/Web-Guide-IV-%3A-Interaction)에 따르면 기본적으로 마우스 입력을 지원한다. 조작이 안 되면 Lively 설정의 Wallpaper → Interaction → Wallpaper Input에서 마우스 입력이 켜져 있는지 확인한다. Lively가 설치되지 않은 경우 브라우저의 배경화면 URL에서 먼저 조절할 수 있다.

## 실행

1. Node.js가 설치된 PC에서 프로젝트 폴더를 열고 `node server.js`를 실행한다.
2. 개인 일정은 브라우저의 `http://127.0.0.1:3000/`에서 입력·수정한다.
3. `http://127.0.0.1:3000/wallpaper.html`을 열어 같은 일정이 보이는지 확인한다.
4. [Lively Wallpaper 공식 저장소](https://github.com/lively-community/lively)의 다운로드 안내를 따라 설치한다.
5. Lively의 배경화면 추가에서 URL로 `http://127.0.0.1:3000/wallpaper.html`을 등록한다.

서버와 Lively가 실행 중이어야 갱신된다. Windows를 다시 켜면 `node server.js`도 다시 실행한다. 자동 시작 등록은 아직 수행하지 않았다. Lively가 화면 갱신을 일시 정지했다면 재개 후 반영된다.

## 기존 개인 일정 옮기기

GitHub Pages 주소와 로컬 주소의 브라우저 저장 공간은 서로 다르다. 기존 웹의 **내 일정 → 개인 일정 내보내기**로 JSON 파일을 다운로드하고, 로컬 웹의 **내 일정 → 개인 일정 가져오기**에서 선택한다. 기존 일정과 같은 ID는 중복 추가하지 않으며 현재 값을 유지한다. 기존 웹에 버튼이 없다면 이 변경을 배포한 뒤 진행한다. 그 뒤에는 로컬 웹에서 편집한 내용이 배경화면에 자동 반영된다. GitHub Pages에서의 이후 수정은 자동으로 전달되지 않는다.

## 저장과 장애 처리

개인 일정 파일은 기본적으로 `%LOCALAPPDATA%\StudyPlanner\tasks.json`에 저장된다. Git 저장소와 공개 Pages에는 포함하지 않는다. `STUDY_PLANNER_DATA_FILE` 환경 변수로 저장 경로를 지정할 수 있다. 로컬 API는 같은 PC에서만 개인 일정을 읽고 쓰도록 제한한다. 브라우저의 localStorage는 캐시와 내보내기용으로 유지한다.

연결 실패 안내가 보이면 서버를 확인한다. 웹 저장 실패 시 브라우저 캐시를 유지해 재연결 때 다시 저장을 시도한다. 배경화면은 마지막으로 읽은 일정을 유지하며 재연결을 시도한다. 학교 자료 제공처에 연결되지 않으면 웹의 기존 공개 자료 스냅샷을 사용하므로 최신 자료가 아닐 수 있다. 개인 일정 파일이 손상되면 덮어쓰지 않고 오류를 표시하므로 먼저 파일을 백업해 복구한다.

## 직접 확인

- 로컬 웹에서 가상의 일정 추가 후 배경화면에 15초 안에 보인다.
- 완료 변경, 날짜 이동, 삭제 후 배경화면에도 같은 상태가 보인다.
- 배경화면에서 클릭·우클릭·드래그로 일정을 수정할 수 없다.
- 학교 일정, 공휴일, 이어지는 여러 날 일정이 웹과 같은 위치에 보인다.
- 서버 종료 시 연결 안내가 보이고 재실행 후 갱신된다.
- 실제 모니터에서 일정이 많은 날을 확인한다. 내용이 넘치면 해당 날짜 안에서 스크롤된다.
- 상단 드래그로 이동하고 네 변·모서리 드래그로 크기를 바꾼 뒤 새로고침하면 배치가 유지된다.
- 배치 잠금 후에는 드래그해도 움직이지 않는다. 잠금 해제·초기화가 동작한다.
- 화면 끝으로 끌거나 화면을 작게 바꾸어도 달력 상단을 다시 잡을 수 있다.
