## 회귀 점검표

| 번호 | 항목 | 이렇게 확인한다 | 통과 조건 | 결과 |
| --- | --- | --- | --- | --- |
| 0 | 콘솔 오류 없음 | 개인 일정이 없는 새 테스트용 브라우저 프로필에서 `index.html`을 열고 개발자 도구 콘솔을 연다. 아래 점검을 마칠 때까지 콘솔을 확인한다. | 페이지를 열 때와 각 조작 뒤에 빨간 오류가 없다. | |
| ① | 추가 | `일정 입력`에서 제목 `영어 단어 10개`, 시작 날짜와 마감 날짜를 모두 내일로 지정하고 `일정 추가`를 누른 뒤 `내 일정`을 본다. | `영어 단어 10개`가 목록에 한 번 나타난다. | |
| ② | 완료 표시(다시 누르면 해제) | `내 일정`에서 `영어 단어 10개`의 완료 체크박스를 한 번 누르고, 같은 체크박스를 다시 누른다. | 첫 클릭 뒤 완료 표시와 취소선이 보이고, 두 번째 클릭 뒤 진행 중 상태로 돌아온다. | |
| ③ | 가운데 일정 삭제 | `수학 문제 5개`를 모레, `과학 복습`을 3일 뒤 마감으로 차례로 추가한다. `내 일정`에서 세 일정이 날짜순으로 보이는지 확인한 뒤 가운데 `수학 문제 5개`의 삭제 버튼을 누른다. | 가운데 일정만 사라지고 `영어 단어 10개`와 `과학 복습`은 남는다. | |
| ④ | 빈 목록 안내 | `내 일정`에서 남은 `영어 단어 10개`와 `과학 복습`을 각각 삭제한다. | 일정 카드가 없고 빈 목록 안내 문구가 보인다. | |
| ④-1 | 빈 제목 | `일정 입력`에서 제목을 비우고 시작·마감 날짜를 내일로 지정한 뒤 `일정 추가`를 누른다. | 일정이 추가되지 않고 제목 입력칸 근처에 한국어 안내 문구가 보인다. | |
| ④-2 | 공백만 입력 | 제목에 스페이스바만 세 번 입력하고 `일정 추가`를 누른다. 안내 문구를 확인한 뒤 `내 일정`을 확인한다. | 공백 제목 일정이 추가되지 않고 제목 입력칸 근처에 안내 문구가 보인다. | |
| ④-3 | 정상 제목 | `일정 입력`으로 돌아가 제목을 `독서 20쪽`으로 바꾸고 오류 안내가 사라지는지 본다. 시작·마감 날짜를 내일로 지정해 `일정 추가`를 누른다. | 제목 오류 안내가 사라지고 `독서 20쪽`이 목록에 나타난다. | |
| ⑤-1 | 추가 유지 | `영어 단어 10개`를 모레, `과학 복습`을 3일 뒤 마감으로 추가한다. `내 일정`에서 세 일정의 순서를 확인하고 새로고침한다. | `독서 20쪽`, `영어 단어 10개`, `과학 복습`이 같은 순서로 남는다. | |
| ⑤-2 | 완료·삭제 유지 | 세 일정 중 `영어 단어 10개`를 완료 표시하고 `과학 복습`을 삭제한 뒤 새로고침한다. | `독서 20쪽`과 완료된 `영어 단어 10개`만 남고 `과학 복습`은 다시 나타나지 않는다. | |
| ⑤-3 | 창 다시 열기 | 테스트용 브라우저의 앱 탭을 닫고 같은 프로필에서 `index.html`을 다시 열어 `내 일정`을 확인한다. | ⑤-2와 같은 두 일정 및 완료 상태가 그대로 보인다. | |
