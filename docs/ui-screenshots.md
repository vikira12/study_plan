# 스플 화면 기록

현재 앱 화면을 두 부분으로 나누어 기록한 스크린샷입니다. 이미지 파일은 `docs/images/`에 보관합니다.

## 월간 달력

월 이동과 오늘 버튼, 요일별 날짜 칸이 있는 달력 화면입니다. 스크린샷에는 2026년 9월이 표시되어 있으며 일정 카드는 없는 상태입니다.

![2026년 9월 월간 달력 화면](images/calendar-overview.png)

## 알림과 일정 관리

마감 알림 영역, 일정 입력 폼, 상태 필터와 제목 검색창, 빈 일정 목록을 보여 줍니다.

![마감 알림과 일정 입력 및 목록 화면](images/task-management.png)

이 문서는 화면 모양을 기록합니다. 기능 동작과 브라우저 콘솔 오류 여부는 별도로 확인해야 합니다.
