# 앱 기획서

## 1. 앱 이름

스플(스터디 플래너)

## 2. 사용자 (누가 쓰나)

학습 일정과 개인 할 일을 혼자 관리하려는 나. 한 기기에서 일정을 등록하고, 남은 일수와 완료 여부를 빠르게 확인한다.

## 3. 해결할 문제 (왜 필요한가)

해야 할 일을 잊거나 마감이 가까워진 뒤에야 알아차리는 문제를 줄인다. 할 일을 한곳에 모아 마감까지 남은 일수를 보여 주고, 임박한 일은 눈에 띄게 알려서 제때 끝낼 수 있게 한다.

## 4. 기능 목록 (꼭 필요한 기능 / 있으면 좋은 기능)

### 꼭 필요한 기능

- 제목, 마감 날짜, 알림 기준을 입력해 할 일을 등록한다. 알림 기준은 1일 전, 3일 전, 7일 전 중에서 고르며 기본값은 1일 전이다.
- 등록한 할 일의 제목, 마감 날짜, 남은 일수, 완료 상태를 목록에서 확인한다.
- 기존 할 일의 제목, 마감 날짜, 알림 기준을 수정한다.
- 할 일을 완료 또는 진행 중으로 표시하고, 필요 없는 할 일은 삭제한다.
- 마감이 임박한 미완료 할 일은 화면에 강조한다. 사용자가 권한을 허용한 경우 브라우저 알림도 한 번 보낸다.
- 마감이 지난 미완료 할 일은 `기한 지남`으로 표시한다.
- 등록·수정·완료 상태를 브라우저에 저장해 새로고침 후에도 유지한다.

### 있으면 좋은 기능

- 전체·진행 중·완료 상태별 필터로 필요한 할 일만 본다.
- 제목 검색으로 특정 할 일을 빠르게 찾는다.
- 할 일이 없거나 검색·필터 결과가 없을 때 안내 문구를 보여 준다.

## 5. 화면 구성 (위에서 아래 순서)

1. 헤더: 앱 이름과 달력·일정 입력 영역·목록으로 바로 이동하는 링크
2. 월간 달력: 월 이동·오늘 버튼, 요일별 날짜 칸, 날짜 안의 일정 카드와 상태 표시
3. 알림 영역: 임박한 일정과 기한이 지난 일정의 요약, 브라우저 알림 허용 버튼
4. 일정 입력 영역: 제목, 마감 날짜, 알림 기준, 등록 버튼, 입력 오류 안내
5. 목록 도구: 전체·진행 중·완료 필터와 제목 검색창
6. 일정 목록: 각 항목의 제목, 마감 날짜, 남은 일수 또는 기한 경과, 완료 체크박스, 수정·삭제 버튼
7. 빈 목록 안내: 등록된 일정이나 검색 결과가 없을 때 보여 주는 문구

## 6. 사용 흐름 (사용자가 하는 행동 순서)

1. 앱을 열어 현재 할 일과 임박한 일을 확인한다.
2. 제목과 마감 날짜, 알림 기준을 입력해 할 일을 등록한다.
3. 목록에서 남은 일수를 확인하고, 필요하면 할 일을 수정하거나 삭제한다.
4. 원하는 할 일을 찾을 때는 필터나 검색을 사용한다(추가 기능).
5. 마감이 가까워지면 화면 경고를 확인한다. 브라우저 알림을 원하면 버튼을 눌러 권한을 허용한다.
6. 일을 마치면 완료로 표시한다. 아직 끝나지 않았다면 진행 중 상태로 되돌릴 수 있다.
7. 다음에 앱을 열어도 저장된 목록과 완료 상태를 이어서 확인한다.

## 7. 만들지 않을 것

- 회원가입, 로그인, 다른 사람과 일정 공유
- 서버나 클라우드를 통한 기기 간 동기화
- 앱을 완전히 닫은 동안 정해진 시각에 보내는 백그라운드 알림
- 프레임워크나 외부 라이브러리가 필요한 기능

구현은 `index.html`, `style.css`, `app.js` 세 파일로 진행하고, 일정 데이터는 사용 중인 브라우저의 `localStorage`에 저장한다. 브라우저 알림을 허용하지 않아도 화면 경고는 볼 수 있게 한다.

## 8. 완료 기준

1. 제목과 오늘 또는 미래의 마감 날짜를 입력해 등록하면 새 할 일이 목록에 보인다.
2. 제목을 비우거나 공백만 입력해 등록하면 오류 안내가 보이고 목록에는 추가되지 않는다.
3. 할 일의 제목·마감 날짜·알림 기준을 수정하면 목록에 변경된 내용이 보인다.
4. 완료 체크박스를 누르면 완료 상태가 표시되고, 다시 누르면 진행 중으로 돌아온다.
5. 삭제 버튼을 누르면 해당 할 일이 목록에서 사라진다.
6. 등록·수정·완료 상태를 바꾼 뒤 새로고침해도 목록과 변경 내용이 유지된다.
7. 마감이 알림 기준 이내로 들어온 미완료 할 일은 화면 상단과 목록에 경고가 보인다. 알림 권한을 허용했다면 브라우저 알림도 한 번 보인다.
8. 할 일을 완료하거나 삭제하면 해당 할 일의 임박 경고가 사라진다.
9. 마감이 지난 미완료 할 일에는 `기한 지남`이 표시된다.

추가 기능을 구현한 경우에는 필터를 바꾸면 해당 상태의 할 일만 보이고, 제목을 검색하면 일치하는 할 일만 보이며, 결과가 없을 때 안내 문구가 보이는지도 확인한다.
