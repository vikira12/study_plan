STUDY PLANNER

스플

학습할 일을 날짜에 맞춰 기록하고 마감 전에 확인하는 개인용 웹앱

월간 달력 · 일정 관리 · 마감 알림

02

PROBLEM

왜 만들었나

해야 할 일을 적어 두어도, 마감이 가까워진 뒤에야 알아차릴 때가 있습니다.

스플은 할 일과 마감 날짜를 달력에서 보여 주고, 남은 일수에 따라 경고를 표시합니다.

03

SCREEN 01

월간 달력

날짜별 일정 카드를 보고, 이전 달·오늘·다음 달로 이동합니다.

04

SCREEN 02

일정 입력과 확인

제목·마감 날짜·알림 기준을 입력하고, 목록에서 상태별로 찾습니다.

05

USER FLOW

사용 흐름

  1. 01할 일 등록제목과 마감 날짜를 정합니다.
  2. 02달력에서 확인날짜별 일정과 남은 일수를 봅니다.
  3. 03마감 알림임박한 일정은 화면에 표시됩니다.
  4. 04완료 처리끝난 일은 체크하고, 필요하면 다시 해제합니다.
06

IMPLEMENTATION

구현 구조

  • index.html화면 구조와 입력 요소
  • style.css달력 격자와 일정 상태별 디자인
  • app.js일정 관리, 날짜 계산, 알림과 로컬 저장

별도 서버 없이 브라우저에서 실행합니다. 일정은 현재 브라우저의 localStorage에 저장되며, 앱을 닫은 동안에는 백그라운드 알림을 보내지 않습니다.

07

DEMO

시연 순서

  1. 오늘 이후의 날짜로 일정을 추가합니다.
  2. 달력 카드와 목록에서 일정을 확인합니다.
  3. 완료 표시를 켰다가 다시 해제합니다.
  4. 일정을 삭제하고 새로고침 후 목록을 확인합니다.
